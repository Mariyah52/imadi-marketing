# Drop your clips here

Upload a vertical phone video (MP4 or MOV, up to 25 MB through the GitHub website).
The next reel slot posts the oldest clip in this folder, with subtitles, IMADI branding,
your WhatsApp number and a closing scene. Then it moves to `clips/used/`.

Want to write the caption yourself? Upload a text file with the same name:
`hook-1.mp4` + `hook-1.txt`.

Tip: name clips so they sort in the order you want them posted, e.g. `01-night-leads.mp4`, `02-ukbot.mp4`.
